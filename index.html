GUIDE / SUPPORTED SUBSET

    
逐行可视化，是怎么工作的？

    
左侧写代码，右侧看每一次变量变化、函数调用与控制台输出。执行到哪一行，左侧那一行就会高亮；遇到 cin / Scanner 时会在控制台暂停，等你输入后继续。

    
行背景表示当前语句；行内更深的绿色框表示正在执行的具体子表达式（例如 cout、if 条件、i++、数组下标或函数调用）。

    
完整语言模式：编辑器底部的「完整编译 ↗」会调用远程 Wandbox 的真实 GCC / OpenJDK 编译运行当前代码，支持更完整的 C++ / Java 语法；该模式只返回编译与运行结果，没有逐行高亮、变量快照和步骤回放，并且需要联网。

    
导入多文件：编辑器右上角「导入」可一次选择多个 .cpp / .h / .java 文件，用文件标签切换。逐行模式只执行当前文件；完整编译会把当前语言的全部文件合并为一个编译单元：C++ 合并头文件和源文件，Java 合并类文件。

已支持的常用语法

        
C++：int / double / char / bool / string、数组、vector、if / else、for / while / do-while、switch、函数与递归、struct / class、构造方法、cout / cin / printf、iomanip 的 fixed / setprecision / setw / setfill。

      重要说明
      
这是一个运行在浏览器里的教学解释器，不是 GCC / Javac 原生编译器。它解释执行 C++ / Java 的常用语法子集，以便暂停、回放并展示每一步状态；不支持 C++ 指针 / 引用、宏与模板，Java 继承 / 接口、异常、文件 I/O、线程、内部类等进阶主题。需要完整语言时，请使用「完整编译」调用真实 GCC / OpenJDK（无逐行状态）。

  • 字符串请用 string，并保留 #include <iostream> 与 using namespace std;。

Java 子集小提示

        
    
          
  • 入口必须是 public static void main(String[] args)。
    • 
          
  • 字符串内容比较请使用 .equals()；本工具对 == 做了内容比较以方便入门演示。

  • 不支持继承、接口、异常、内部类；一个文件可以放多个普通类。
